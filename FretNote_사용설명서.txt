FretNote — 기타 코드 자판 악보 스튜디오
버전: 1.5 (1박 운지 지판 + 박자별 코드 길이 재생) / 2026-11-17

[시작하기]
1. 압축을 풀고 guitar_chord_score_studio.html 파일을 Chrome 또는 Edge로 엽니다.
2. 설치나 로그인, 서버와 인터넷이 필요하지 않습니다.
3. 처음에는 C → G → Am → F의 4마디 예시 악보가 나타납니다. 「＋ 새 악보」는 1마디부터 시작합니다.
4. 「＋ 새 악보」로 빈 악보를 만들거나, 제공된 FretNote_예시악보.json 파일을 「JSON 불러오기」로 열어 박자별 배치를 확인하세요.

[1박 운지 지판과 정확한 코드 재생 · v1.5 신규]
- 악보 「자판 보기」에서 1박 블록도 코드 이름, 1박 표시, 6현 운지 지판을 함께 표시합니다. 「코드 보기」는 별도 간단 보기이므로 운지표를 숨깁니다.
- 모바일에서 4/4 또는 6/8 등 박자 칸이 좁으면 각 마디 안의 박자 영역을 좌우로 스크롤해 운지를 읽을 수 있습니다. 인쇄·PDF에서도 운지도가 표시됩니다.
- 박자 칸 수는 실제 코드 지속 시간입니다. 4/4, 120 BPM에서 C 1박=0.5초, G 2박=1.0초, Am 1박=0.5초입니다.
- 6/8은 한 칸이 8분음표이므로 120 BPM에서 1칸=0.25초입니다(표시 BPM은 4분음표 기준).
- 「매 박 스트로크」는 코드가 이어지는 박자마다 다시 튕깁니다. 「박자별 아르페지오」는 박자 안에서 각 줄을 순차적으로 튕깁니다.
- 「시작 1회 · 길이 유지」는 코드 첫 박자에 한 번 튕기고 지정된 코드 끝에서 소리를 멈춥니다. 실제 기타처럼 감쇠하므로 긴 코드는 소리가 자연스럽게 작아질 수 있습니다.
- 다음 코드 또는 쉼표·빈 박자가 시작하면 이전 코드의 잔향을 끊습니다. 메트로놈은 선택했을 때만 빈 박자에서도 클릭 소리를 냅니다.
- 기존 악보의 start/beats/voicing·저장 목록·바레 지도 및 v1.4 JSON 구조를 그대로 유지합니다.

[마디 수 자유 설정 · v1.4 신규]
- 「원하는 마디 수로 악보 구성」에서 1~800마디를 입력한 다음 「마디 수 적용」을 누릅니다. − / ＋ 버튼으로 1마디씩 조절할 수도 있습니다.
- 「＋ 새 악보」는 1마디짜리 빈 악보로 시작하며 예시 악보의 C → G → Am → F는 4마디를 유지합니다.
- 4/4는 1마디의 4분음표 수를 뜻하며 전체 4마디 고정이 아닙니다. 3/4 또는 6/8과 마디 수는 별도로 설정합니다.
- 코드가 놓인 마디까지 줄이려 하면 코드 유실을 막기 위해 요청을 거절합니다. 먼저 뒤쪽 코드를 앞쪽으로 옮기거나 삭제하세요.
- 마디를 넘어 이어지는 코드는 유지되며 필요한 만큼 전체 마디가 늘어납니다. 「끝의 빈 마디 모두 정리」는 뒤쪽 빈 마디만 정리합니다.
- 지정한 마디 수는 악보 자동 저장, 개별 JSON, 전체 목록 백업에 함께 보존됩니다. 기존 v1.3 JSON도 불러올 수 있습니다.

[기타 소리로 듣기 · v1.4 신규]
- 코드 목록의 ♪, 오른쪽 「♪ 선택한 운지 소리 듣기」, 바레 코드 지도 「♪ 운지 소리 듣기」 버튼에서 개별 코드 소리를 확인합니다.
- 「▶ 악보 재생」은 첫 마디부터 지정된 마지막 마디까지 재생하며, 현재 마디·박자와 코드가 화면에 강조 표시됩니다. 「■ 정지」로 멈춥니다.
- 연주 패턴: 매 박 스트로크 / 박자별 아르페지오 / 시작 1회·길이 유지. 반복, 메트로놈을 선택할 수 있습니다.
- 템포(BPM), 3/4·4/4·6/8 박자표, 실제 운지와 카포가 소리에 적용됩니다. 6/8의 1칸은 8분음표이며 BPM은 4분음표 기준입니다.
- 표준 튜닝의 기타 줄을 Web Audio(웹 오디오)로 합성하는 방식이므로 실제 기타 녹음 음색과는 차이가 있습니다. 인터넷·외부 음원·로그인 불필요.
- 브라우저 자동재생 정책에 따라 소리 버튼을 직접 눌러야 합니다. 빈 악보에서는 코드가 없을 경우 메트로놈만 켜서 연습할 수 있습니다.
- MP3/WAV 오디오 내보내기 및 음별 TAB/오선보 제작은 지원하지 않습니다.

[검증]
- v1.5: C 1박 → G 2박 → Am 1박의 음 끝 시점 및 세 연주 패턴, 모바일 320/390px, 6/8 가로 스크롤, 인쇄 지판 표시 검증 PASS.
- 데스크톱·모바일 브라우저 자동화: 새 악보 1마디, 7마디 확장, 6마디 축소, 코드 있는 마디 축소 방지, 박자 배치, 저장/재열기 PASS.
- 소리 미리 듣기, 악보 재생/정지, 메트로놈, 바레 지도 24개 위치, JSON 저장 PASS.
- 모든 사운드 카드의 실제 출력 음질이나 모든 OS/브라우저 조합은 별도 보증하지 않습니다.

[박자 맞춰 코드 배치하기]
1. 왼쪽 코드 라이브러리에서 원하는 코드를 클릭하거나 선택합니다.
2. 악보 아래의 「1박·2박·3박·4박」 버튼에서 코드 길이를 선택합니다.
3. 악보의 마디마다 표시된 1·2·3·4 박자 숫자 또는 빈칸의 +를 클릭하면 해당 박자에 코드가 들어갑니다.
4. 라이브러리 코드 카드를 악보 박자 위치로 끌어 놓아도 됩니다.
5. 악보에 들어간 코드를 다시 끌어 다른 마디·박자로 이동할 수 있습니다.
6. 기존 코드와 겹치면 이전 코드를 삭제하거나 덮어쓰지 않고, 겹치는 코드들을 뒤로 자동 이동합니다.
7. 코드 블록을 클릭하면 아래 편집기에서 마디 번호·시작 박자·블록 길이·가사/메모를 직접 고칠 수 있습니다.
8. 「＋ 빈 마디 추가」로 미래 마디를 준비합니다. 「마지막 빈 마디 정리」는 사용하지 않은 뒤쪽 마디만 제거합니다.

[읽기 쉬운 악보 보기]
- 자판 보기: 각 코드 블록에 기타 운지 도표 표시. 1박 블록도 운지 지판을 표시하며 좁은 화면은 가로 스크롤로 확인.
- 코드 보기: 도표 없이 코드명만 보여 주고, 일반 화면에서 2마디씩 나란히 배치.
- 각 마디의 1·2·3·4 박자 칸은 동일한 너비입니다. 긴 코드는 해당 칸을 차지합니다.
- 다른 마디까지 이어지는 코드는 다음 마디에 ↳ 기호로 연결을 표시합니다.
- 비어 있는 박자는 점선 빈칸으로 남습니다.
- 모바일: 드래그 대신 코드 선택 → 박자 번호 터치; 정확한 이동은 블록의 마디/시작 박자 입력 사용.

[바레 코드 전체 지도 · v1.3 신규]
1. 화면 상단 「▦ 바레 코드 전체 지도」 또는 코드 라이브러리 하단 버튼을 누릅니다.
2. E형(6번 줄 루트)과 A형(5번 줄 루트)을 1~12프렛 전체에서 비교할 수 있습니다.
3. 코드 종류(메이저/마이너/7/maj7/m7/sus2/sus4/add9)를 변경할 수 있습니다.
4. 12개 위치 × 두 가지 이동형 = 코드 종류별 24개의 운지를 목록으로 표시합니다.
5. 지판의 근음 또는 아래 운지표를 누르면 선택 코드, 프렛, 운지 자판이 갱신됩니다.
6. 「＋ 이 코드 악보에 추가」를 누르면 현재 박자 길이로 악보 끝에 배치됩니다.
7. 「편집 화면에서 보기」는 선택한 코드를 유지하고 지도를 닫습니다. 악보의 원하는 박자 칸에 코드를 드래그/배치할 수 있습니다.
8. 12프렛 루트형은 0프렛의 개방현과 구분되어 별도 운지형으로 저장됩니다.
- 길게 누르는 바레는 코드 도표에 진한 수평선으로 표시합니다. 근음이 다른 코드는 같은 소리라도 E형과 A형의 포지션이 다릅니다.
- 이 지도는 가장 널리 쓰는 E형/A형 이동식 바레 운지를 대상으로 합니다. CAGED의 C형·G형·D형 및 모든 대체운지를 망라한 도감은 아닙니다.

[저장한 악보 목록]
- 현재 악보는 브라우저에 자동 저장되며 「저장한 악보」 목록에서 각각 열 수 있습니다.
- 「현재 악보 저장」: 지금 편집 중인 악보를 해당 목록 항목에 저장.
- 「다른 이름으로 저장」: 독립적인 복사본을 만들어 원본은 그대로 보관.
- 각 목록 카드에서 열기 / 이름 변경 / 복제 / 삭제 가능.
- 「전체 목록 백업」: 모든 악보를 하나의 JSON 파일로 다운로드.
- 「목록 가져오기」: 전체 백업 JSON을 읽고 기존 목록에 별도 항목으로 추가(덮어쓰지 않음).
- 상단 「JSON 저장」과 「JSON 불러오기」는 개별 악보 파일용.
- 기존 FretNote 1.0 개별 악보/1.1 저장 목록도 읽어서 순차 박자 위치로 자동 변환합니다.

[기타 기능]
- 표준 6현 기타, 표준 튜닝 E A D G B e.
- 12개 근음 × 8종류 = 96개 코드, 오픈 포지션 및 5·6번 줄 루트형 운지 전환. 바레 코드 24개 위치를 코드 종류별로 일괄 표시.
- 선택한 코드의 구성음과 12프렛 지판 표시.
- 4/4·3/4·6/8 박자표, 템포(BPM), 카포 설정.
- 실행 취소(Ctrl+Z), 다시 실행(Ctrl+Y), 현재 악보 저장(Ctrl+S), 삭제(Delete), 선택 해제(Esc).
- 「악보 인쇄 · PDF」는 브라우저 인쇄 대화상자로 연결되며 PDF로 저장도 가능.
- 텍스트 코드 악보 내보내기에는 각 박자 위치와 빈 박자가 포함됨.

[주의사항]
- 이 프로그램은 화음(코드) 운지를 정해 배치하는 코드 악보용입니다. 멜로디 오선보, 음별 타브 악보, 오디오 파일(MP3/WAV) 내보내기 기능은 없습니다.
- 4/4와 3/4에서는 1칸이 4분음표, 6/8에서는 1칸이 8분음표입니다.
- 박자표를 변경하면 기존 코드의 '칸 번호'는 그대로 유지되며, 마디 구획만 새 박자표에 따라 달라집니다.
- 카포를 적용해도 표시 코드명은 실제 울림음이 아닌 운지 기준 이름입니다.
- 일부 7화음 운지는 5음이 생략될 수 있습니다.
- 브라우저의 로컬 저장은 사이트/파일 위치 및 브라우저 데이터 정리에 영향을 받습니다.
  파일을 다른 위치로 옮기거나 브라우저 데이터를 지우기 전, 「전체 목록 백업」으로 반드시 보관하세요.
- 압축 해제 후 HTML 파일을 열면 동작합니다. 파일 안에 코드/이름/개인정보를 외부로 전송하는 기능은 없습니다.
